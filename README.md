# 🌿 글숲 (Geulsoop) | 종합 문학 & 창작 플랫폼 웹사이트 (최종 완료)

아마추어 작가들과 감성적인 독자를 연결하는 종합 문학 플랫폼 **글숲(Geulsoop)**의 최종 완성본 코드입니다.
운문(시/시조/디카시), 산문(수필/소설/에세이), 극/영상(시나리오/대본), 기타/음악(가사/팟캐스트) 등 다양한 창작물을 나누고 소통할 수 있습니다.

---

## 📁 전체 폴더 및 파일 구조 (Directory Structure)

```text
글쓰기/
├── index.html                  # [1단계] 메인 홈 (추천 슬라이더, 실시간 인기글, 작가소식, 모달)
├── README.md                   # 프로젝트 전체 개발 명세서
├── css/
│   ├── style.css               # 글로벌 디자인 시스템 (웜 아이보리/포레스트 그린 팔레트, 폰트, 리셋)
│   ├── components.css          # 헤더, 카드 그리드, 슬라이더, 에디터, 댓글/삭제, 모달, 푸터 Stylesheet
│   └── responsive.css          # 모바일 및 태블릿 반응형 레이아웃 Breakpoint Stylesheet
├── js/
│   ├── data.js                 # [4단계] LocalStorage 데이터 영구저장 (작품, 좋아요, 조회수, 댓글 상태 동동화 엔진)
│   ├── slider.js               # 이주의 추천 작품 인터랙티브 슬라이더 배너 클래스
│   ├── gallery.js              # [2단계/4단계] 장르별 필터링, 정렬, 뷰 전환, 본문/댓글 작성/삭제 처리 엔진
│   ├── write.js                # [3단계] 창작 에디터, 서식 정렬, 미리보기 및 출간 발행 엔진
│   └── main.js                 # 메인 홈 컨트롤러 (실시간 탭, 읽기 모달, 모바일 드로어)
└── pages/
    ├── gallery.html            # [2단계/4단계] 장르별 작품 관람 및 상세 읽기/댓글 작성·삭제 페이지
    ├── lounge.html             # [4단계 완료] 작가 라운지, 합평회, 창작 팁 공유 & 글쓰기 모임 커뮤니티
    └── write.html              # [3단계] 창작 및 투고 에디터 & 작품 출간 발행 페이지
```

## 🚀 단계별 구현 기능 요약

### 1단계: 메인 레이아웃 및 디자인 시스템
- **디자인 팔레트**: 지면 느낌의 `웜 아이보리(#FDFBF7)` + `포레스트 그린(#244232)` + `웜 골드(#C69852)`
- **타이포그래피**: 감성 서정 폰트 **'고운바탕(Gowun Batang)'** + 명확한 UI 폰트 **'Noto Sans KR'**
- **인터랙티브 요 요소**: 이주의 추천작 슬라이더 배너, 오늘의 한 문장 위젯, 실시간 인기글 카드 그리드, 모바일 드로어 메뉴

### 2단계: 장르별 작품 관람 및 상세 모달 (`pages/gallery.html`)
- **대장르/소장르 필터**: `운문(시, 시조, 동시, 디카시)`, `산문(수필, 소설, 에세이)`, `극/영상(시나리오, 대본)`, `기타/음악(가사, 팟캐스트)`
- **정렬 및 뷰 전환**: 최신순, 인기순, 조회순, 댓글순 정렬 및 `카드 그리드 뷰` ↔ `리스트 뷰` 전환
- **독서 옵션**: 글자 크기 조절(`A+`, `A-`) 및 3가지 독서 테마(`아이보리`, `웜그레이`, `다크모드`)

### 3단계: 창작 및 투고 에디터 (`pages/write.html`)
- **에디터 폼**: 제목, 필명, 작가 한마디, 대장르/소장르 동적 드롭다운, 태그, 본문 작성
- **서식 & 템플릿**: 운문용 중앙 정렬, 볼드, 인용구 삽입 및 `시`, `에세이`, `가사`, `대본` 샘플 템플릿 제공
- **작품 발행**: 발행 즉시 서재 목록 최상단에 실시간 등록 및 자동 이동

### 4단계: 데이터 상태 관리, 댓글 삭제 & 네비게이션 완성
- **LocalStorage 영구 유지**: 페이지를 새로고침해도 **발행한 글, 증가한 좋아요 수, 작성된 댓글**이 모두 유지됨
- **인터랙션 연동**:
  - 좋아요(하트) 실시간 토글 및 카운터 동기화
  - 댓글 작성 및 **실시간 댓글 삭제(`🗑️ 삭제`)** 기능 구현
- **네비게이션 & 커뮤니티**:
  - `홈`, `작품 관람`, `작가 라운지`, `창작 및 투고` 4개 메인 상단 메뉴 완벽 연동
  - `pages/lounge.html` 작가 프로필, 작품 합평회, 창작 팁, 소모임 모집 커뮤니티 완성
